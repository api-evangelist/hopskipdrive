# HopSkipDrive

> HopSkipDrive is a supplemental student transportation company. School districts,
> charter networks, county offices, government agencies and nonprofits book and monitor
> rides through RideIQ, HopSkipDrive's web platform; families track trips in the
> HopSkipDrive mobile app; vetted CareDrivers work from a driver app. RouteWise AI is
> HopSkipDrive's routing-analysis product for modelling a district's fleet, student base
> and constraints. HopSkipDrive reports 5M+ completed rides across 14,000+ schools and
> 2,000+ districts.

**API status: no public API.** As of 2026-08-04 HopSkipDrive publishes no developer
portal, no API documentation, no OpenAPI/AsyncAPI/GraphQL contract, no MCP server and no
A2A agent card. Its platform is account-gated commercial software. A private versioned
REST backend (`api.hopskipdrive.com`, `v1`) and a WebSocket event stream
(`wss://events.hopskipdrive.com/ws/sub`) back the RideIQ web app, but neither is
documented for third-party use and every unauthenticated path returns 404. Do not
attempt to call them; contact HopSkipDrive for integration.
